# ACME CLOUD — DEMO SECURITY OVERVIEW

This file is synthetic evidence for the Atlas proof of value.

## Encryption
Customer traffic is encrypted in transit using TLS 1.2 or later. Customer data is encrypted at rest using AES-256.

## Access control
Administrative access to production requires multi-factor authentication and is restricted through role-based access control.

## Vulnerability management
Critical vulnerabilities have a remediation target of 21 calendar days. High vulnerabilities have a target of 45 calendar days.

## Business continuity
The production recovery time objective is 6 hours. Disaster recovery exercises are performed annually.

## Independent assurance
Acme Cloud completed a SOC 2 Type II examination covering the period ending 30 June 2026. The report is available to customers under NDA.
